# Mini Blackjack

Console version of Blackjack written in Python.

## Main features

- Deals cards to player and dealer from a virtual deck.
- Handles hit and stand choices.
- Treats Aces as 1 or 11 depending on the hand.
- Compares scores and prints win, lose or draw.

## What I learned

- Representing a deck of cards with lists.
- Using `random` to draw cards.
- Implementing game rules and edge cases step by step.

## How to run

Open `main.py` in Python 3 and run the file.
